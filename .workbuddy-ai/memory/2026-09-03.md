## Fix: donut chart jelek di mobile (Larapex pitfall)

**Gejala:** donut (Status Aset / Status Tiket) di mobile jadi lonjong & legend overflow.
Akar: Larapex default `height=500` + CSS lama `.apexcharts-canvas svg{width:100%}`
membentangkan SVG (tinggi tetap, lebar 100%) → ellipse.

**Pitfall Larapex:** `setOptions()` **diabaikan** oleh Blade `script()` stub bawaan
(hardcode setter terbatas). `setOptions()` hanya sampai ke `toJson()`/`getOptions()`,
bukan ke browser. Solusi: publish view
`php artisan vendor:publish --tag=larapex-charts-views --force` → override
`resources/views/vendor/larapex-charts/chart/script.blade.php` supaya render dari
`$chart->getOptions()` (+ inject `chart.id` dan `labels` dari `$chart->labels()`).

`DashboardChart` donut: `->setHeight(300)`, `->setToolbar(false)`,
`->setOptions($this->donutOptions())` (legend bottom, donut size 68%, `responsive`
breakpoint 480 → height 250 / legend 11px / donut 62%). Hindari set scalar `chart.*`
di `setOptions()` (array_merge_recursive bikin jadi array). CSS `.chart-wrap`: buang
`svg{width:100%}`, cukup `.apexcharts-canvas{width:100% !important; margin:0 auto}`.
`width` Larapex default sudah `'100%'`.
